
# NLP Study Notes: Lemmatization


## 1. What is lemmatization?

**Lemmatization is an NLP text-normalization technique that converts a word into its canonical dictionary form, called its lemma.** It considers linguistic information such as the word's grammatical role and, depending on the method, its context.

For example\:

| Original word | Lemma | Explanation |
|--------|--------|--------|
| running | run | Verb form |
| runs | run | Third-person singular verb |
| ran | run | Irregular past-tense verb |
| studies | study | Inflected form |
| better | good | Comparative adjective, in the appropriate context |
| was | be | Past-tense form |
| mice | mouse | Irregular plural noun |
| cars | car | Plural noun |

Notice that lemmatization does not simply remove letters from a word. It tries to identify the correct base form.

For example, removing `-ing` from `running` produces `runn`, which is incorrect. A lemmatizer can identify `run` as the correct lemma.

### Why is lemmatization necessary?

Consider these sentences\:

1. The student **studies** machine learning.
2. The student **studied** machine learning.
3. The student is **studying** machine learning.

Although the verb forms differ, all three express the concept of studying.

Lemmatization can normalize them\:

- studies → study
- studied → study
- studying → study

This can reduce vocabulary variation and help an NLP system recognize related word forms as the same lexical item.

However, lemmatization does not guarantee that different words with similar meanings will become identical. For example, `learn`, `study`, and `understand` generally retain different lemmas.

## 2. How lemmatization works

A lemmatizer may use a dictionary, morphological rules, grammatical information, and sometimes surrounding context to determine a word's base form.

**Input text**

The students were studying.

**Tokenization**

The &#124; students &#124; were &#124; studying

**Grammatical analysis**

Determine the POS and relevant word forms

**Lemma lookup and normalization**

Use lexical information and morphology

**Output**

the &#124; student &#124; be &#124; study

This is a simplified conceptual pipeline. Individual tools perform these steps differently, and some integrate POS tagging and lemmatization into the same processing pipeline.

### Step 1: Tokenization

The input sentence is divided into tokens.

```python
text = "The students were studying."

tokens = ["The", "students", "were", "studying", "."]
```

### Step 2: Determine grammatical information

The system may identify\:

| Word | POS category |
|--------|--------|
| students | Noun |
| were | Auxiliary verb |
| studying | Verb |

This information helps determine which lemma is appropriate.

### Step 3: Find the base form

The lemmatizer applies the appropriate lexical or morphological analysis\:

```text
students  → student
were      → be
studying  → study
```

### Step 4: Produce normalized text

The resulting tokens can be used for searching, document analysis, or machine learning.

One important point: **lemmatization is not the same as changing a sentence into grammatically correct base-form English.** It normalizes individual words; it does not rewrite the sentence's syntax.

## 3. Stemming vs. lemmatization

This is one of the most important comparisons in NLP.

**Stemming** attempts to reduce words to stems, often by removing prefixes or suffixes. The result does not necessarily have to be a valid dictionary word.

**Lemmatization** attempts to return a valid lexical base form, using linguistic information.

## Compare the two approaches

**Stemming**

Uses relatively simple reduction rules.

---

studies → studi

caring → care (possible)

relational → relat (possible)

**Lemmatization**

Uses vocabulary and linguistic analysis.

---

studies → study

caring → care (verb, depending on context)

relational → relational (often)

Examples of stemming depend on the specific algorithm, such as Porter or Snowball. Stemmers do not all produce the same result.

### Detailed differences

| Feature | Stemming | Lemmatization |
|--------|--------|--------|
| Main method | Suffix/prefix reduction rules | Lexical and morphological analysis |
| Uses POS information | Usually no | Often, depending on the tool |
| Requires a dictionary | Not necessarily | Commonly uses lexical resources |
| Output is a valid word | Not guaranteed | Usually intended to be |
| Handles irregular forms | Limited | Often better |
| Computational cost | Usually lower | Often higher |
| Example: `studies` | `studi` with some stemmers | `study` |
| Example: `better` | Depends on the stemmer | `good` when interpreted as a comparative adjective |
| Best suited for | Simple search normalization and some retrieval tasks | Linguistically informed normalization |

### Python comparison using NLTK

```python
import nltk
from nltk.stem import PorterStemmer, WordNetLemmatizer

stemmer = PorterStemmer()
lemmatizer = WordNetLemmatizer()

words = ["studies", "playing", "cars", "better"]

for word in words:
    stem = stemmer.stem(word)
    lemma = lemmatizer.lemmatize(word)

    print(
        f"{word:10} "
        f"Stem: {stem:10} "
        f"Lemma: {lemma}"
    )
```

Example output\:

```text
studies    Stem: studi      Lemma: study
playing    Stem: play       Lemma: playing
cars       Stem: car        Lemma: car
better     Stem: better     Lemma: better
```

Why does the lemmatizer return `playing` instead of `play` and `better` instead of `good`?

Because NLTK's `WordNetLemmatizer` assumes a noun by default. It does not automatically infer the correct grammatical category from the sentence.

We'll fix this in the next section.

## 4. Why POS tagging is important for lemmatization

Lemmatization becomes more effective when the system knows how a word is used grammatically.

Consider the word `meeting`\.

| Sentence | Grammatical role | Possible lemma |
|--------|--------|--------|
| The meeting was long. | Noun | meeting |
| They are meeting today. | Verb | meet |

The same surface word can have different lemmas depending on its role.

Similarly, consider `better`\:

- "This is a better solution." → adjective → `good`
- "I can do better." → adverb → `well` in the appropriate interpretation
- "I want to better my skills." → verb → `better` may remain unchanged

A lemmatizer without POS information may not choose the intended base form.

### 4.1 Using NLTK with POS information

First, download the required resources\:

```python
import nltk

nltk.download("wordnet")
nltk.download("omw-1.4")
nltk.download("averaged_perceptron_tagger_eng")
```

Now let's compare lemmatization with and without POS information.

```python
from nltk.stem import WordNetLemmatizer

lemmatizer = WordNetLemmatizer()

print(lemmatizer.lemmatize("playing"))
print(lemmatizer.lemmatize("playing", pos="v"))

print(lemmatizer.lemmatize("better"))
print(lemmatizer.lemmatize("better", pos="a"))
```

Output\:

```text
playing
play
better
good
```

The `pos` argument tells the lemmatizer how to interpret the word\:

- `"n"` — noun
- `"v"` — verb
- `"a"` — adjective
- `"r"` — adverb

### 4.2 Automatically map POS tags to WordNet categories

NLTK's POS tagger returns Penn Treebank tags such as `NN`, `VBZ`, `JJ`, and `RB`\. The WordNet lemmatizer expects a different POS format.

We need to convert between them.

```python
import nltk
from nltk.stem import WordNetLemmatizer
from nltk.corpus import wordnet

nltk.download("punkt_tab")
nltk.download("averaged_perceptron_tagger_eng")
nltk.download("wordnet")
nltk.download("omw-1.4")

lemmatizer = WordNetLemmatizer()

def get_wordnet_pos(treebank_tag):
    if treebank_tag.startswith("J"):
        return wordnet.ADJ
    elif treebank_tag.startswith("V"):
        return wordnet.VERB
    elif treebank_tag.startswith("N"):
        return wordnet.NOUN
    elif treebank_tag.startswith("R"):
        return wordnet.ADV

    return None

def lemmatize_text(text):
    tokens = nltk.word_tokenize(text)
    tagged_tokens = nltk.pos_tag(tokens)

    lemmas = []

    for word, tag in tagged_tokens:
        wn_pos = get_wordnet_pos(tag)

        if wn_pos is not None:
            lemma = lemmatizer.lemmatize(word, pos=wn_pos)
        else:
            lemma = word

        lemmas.append(lemma)

    return lemmas

text = "The students were studying and the children ran quickly."

print(lemmatize_text(text))
```

The output will be a list of normalized tokens. For example, `students` can become `student`, `studying` can become `study`, and `ran` can become `run`, depending on the predicted POS tags.

**Why this is better\:** the POS tagger provides grammatical information before the lemmatizer selects the base form.

**Limitation\:** this implementation uses a relatively simple mapping and a default fallback for unhandled tags. A predicted POS tag can also be wrong, so POS-aware lemmatization is not guaranteed to produce the intended lemma every time.

## 5. Lemmatization using spaCy

spaCy is one of the most convenient libraries for practical NLP because it can tokenize text, assign POS tags, and generate lemmas through its language-processing pipeline.

### 5.1 Installation

In your Python environment, run\:

```bash
pip install spacy
python -m spacy download en_core_web_sm
```

The second command downloads the small English language model.

### 5.2 Basic implementation

```python
import spacy

nlp = spacy.load("en_core_web_sm")

text = "The students were studying and the children ran quickly."

doc = nlp(text)

for token in doc:
    print(token.text, token.pos_, token.lemma_)
```

Illustrative output\:

```text
The       DET    the
students  NOUN   student
were      AUX    be
studying  VERB   study
and       CCONJ  and
the       DET    the
children  NOUN   child
ran       VERB   run
quickly   ADV    quickly
.         PUNCT  .
```

Exact POS tags and lemma outputs can vary with the spaCy model version and context.

### 5.3 Understanding the important attributes

| Attribute | Purpose | Example |
|--------|--------|--------|
| `token.text` | Original token | `studying` |
| `token.pos_` | Coarse POS category | `VERB` |
| `token.tag_` | Fine-grained POS tag | `VBG` |
| `token.lemma_` | Lemma | `study` |
| `token.is_stop` | Whether the token is a recognized stop word | `True` or `False` |
| `token.is_punct` | Whether the token is punctuation | `True` or `False` |

The trailing underscore matters\:

- `token.pos_` returns a readable string such as `"VERB"`\.
- `token.pos` returns an integer ID.

Similarly, `token.lemma_` returns the readable lemma, while `token.lemma` returns its internal integer ID.

### 5.4 Lemmatization of ambiguous words

```python
import spacy

nlp = spacy.load("en_core_web_sm")

sentences = [
    "I booked a room.",
    "I read a book.",
    "The children are playing.",
    "The meeting was interesting."
]

for sentence in sentences:
    doc = nlp(sentence)

    print(f"\nSentence: {sentence}")

    for token in doc:
        if not token.is_punct:
            print(
                f"{token.text:12} "
                f"{token.pos_:8} "
                f"{token.lemma_}"
            )
```

This exercise helps you see how the model treats nouns, verbs, auxiliaries, and other categories differently.

### 5.5 Extract only the lemmas

Sometimes you don't need the POS tags in your output.

```python
text = "The students were studying machine learning."

doc = nlp(text)

lemmas = [
    token.lemma_
    for token in doc
]

print(lemmas)
```

Example output\:

```python
[
    "the",
    "student",
    "be",
    "study",
    "machine",
    "learning",
    "."
]
```

If you want to omit punctuation\:

```python
lemmas = [
    token.lemma_
    for token in doc
    if not token.is_punct
]
```

If you also want to remove stop words\:

```python
lemmas = [
    token.lemma_
    for token in doc
    if not token.is_punct and not token.is_stop
]
```

Be careful with the last example: removing stop words may discard important words such as `not`, which can reverse sentiment.

## 6. Types and approaches to lemmatization

Lemmatization can be implemented in several ways.

### 6.1 Dictionary-based lemmatization

A dictionary-based approach uses a lexical resource containing words and their canonical forms.

For example\:

```python
lemma_dictionary = {
    "cars": "car",
    "mice": "mouse",
    "went": "go",
    "children": "child"
}

def dictionary_lemmatize(word):
    return lemma_dictionary.get(word.lower(), word.lower())

print(dictionary_lemmatize("cars"))      # car
print(dictionary_lemmatize("children"))  # child
print(dictionary_lemmatize("went"))      # go
```

This is a simplified demonstration, not a complete lemmatizer. A real dictionary-based system needs a large vocabulary and often needs POS information to resolve ambiguity.

**Advantages\:**

- Easy to understand.
- Reliable for entries explicitly covered by the dictionary.
- Useful for demonstrating irregular forms.

**Limitations\:**

- Unknown words may remain unchanged.
- The dictionary requires maintenance and broad coverage.
- A word may have different lemmas depending on context.

### 6.2 Rule-based morphological lemmatization

A rule-based system applies linguistic rules to word forms.

For example, for some English plural nouns\:

```text
cars      → car
books     → book
students  → student
```

However, simple suffix stripping fails for irregular forms\:

```text
mice      → mouse
children  → child
went      → go
```

A good lemmatizer therefore combines morphological rules with lexical information rather than relying exclusively on suffix removal.

### 6.3 Context-aware lemmatization

A context-aware system considers the word's grammatical role or its use in a sentence.

For example\:

```text
They are running.  → running → run
The running water. → running may remain running
```

The exact output depends on the model's analysis and the grammatical interpretation.

Modern NLP pipelines commonly use POS tagging and contextual features to improve normalization.

## 7. Lemmatization on a Pandas DataFrame

Suppose you have a movie-review dataset for sentiment analysis\:

| review |
|--------|
| The actors performed brilliantly. |
| The story was boring. |
| I loved the movies. |
| The characters were running away. |

Your goal is to add a new column containing normalized tokens.

### 7.1 Basic approach

```python
import pandas as pd
import spacy

nlp = spacy.load("en_core_web_sm")

df = pd.DataFrame({
    "review": [
        "The actors performed brilliantly.",
        "The story was boring.",
        "I loved the movies.",
        "The characters were running away."
    ]
})

def lemmatize_text(text):
    doc = nlp(str(text))

    return [
        token.lemma_
        for token in doc
        if not token.is_punct
    ]

df["lemmas"] = df["review"].apply(lemmatize_text)

print(df[["review", "lemmas"]])
```

This adds a `lemmas` column to the DataFrame.

### 7.2 Why use `str(text)`?

A DataFrame can contain missing values such as `NaN` or `None`\. Passing a missing value directly into an NLP pipeline may cause problems.

A safer approach is\:

```python
df["review"] = df["review"].fillna("").astype(str)

df["lemmas"] = df["review"].apply(lemmatize_text)
```

This converts missing reviews to empty strings and ensures the values are strings before processing.

### 7.3 Efficient processing for larger datasets

If you have 1,000 or more reviews, you can use `nlp.pipe()` to batch-process texts instead of calling `nlp()` separately for each row.

```python
texts = df["review"].fillna("").astype(str)

df["lemmas"] = [
    [
        token.lemma_
        for token in doc
        if not token.is_punct
    ]
    for doc in nlp.pipe(texts, batch_size=128)
]
```

`nlp.pipe()` generally reduces Python-level overhead and can improve throughput, especially on larger datasets. The best batch size depends on the length of your reviews and available memory.

If you need only lemmas and not POS tags, dependencies, or named entities, you can disable unnecessary components when loading the model or processing documents. Keep the tagger/morphological components required for correct lemmatization enabled.

## 8. Using lemmatization for machine learning and text classification

Lemmatization can be useful when preparing text for traditional machine learning algorithms such as Logistic Regression, Naive Bayes, SVM, and other classifiers.

Consider the following reviews\:

```text
Review 1: The actors performed brilliantly.
Review 2: The actor performs brilliantly.
Review 3: The actor performed well.
```

Lemmatization can normalize some variations\:

```text
actors    → actor
performed → perform
performs  → perform
```

This may help a text vectorizer recognize related word forms.

### 8.1 Combine lemmatization with TF-IDF

```python
import spacy
from sklearn.feature_extraction.text import TfidfVectorizer

nlp = spacy.load("en_core_web_sm")

reviews = [
    "The actors performed brilliantly.",
    "The actor performs brilliantly.",
    "The story was boring.",
    "The stories were boring."
]

def lemmatize_for_tfidf(text):
    doc = nlp(text)

    return " ".join(
        token.lemma_.lower()
        for token in doc
        if not token.is_punct
    )

normalized_reviews = [
    lemmatize_for_tfidf(review)
    for review in reviews
]

vectorizer = TfidfVectorizer()

X = vectorizer.fit_transform(normalized_reviews)

print("Normalized reviews:")
print(normalized_reviews)

print("\nVocabulary:")
print(vectorizer.get_feature_names_out())

print("\nFeature matrix shape:", X.shape)
```

The variable `X` contains the TF-IDF feature matrix. You can use it as input to a classification algorithm.

For a real sentiment-analysis project, fit the vectorizer only on the training data and transform the test data separately to prevent data leakage.

### 8.2 Does lemmatization always improve accuracy?

No. It depends on the dataset and the task.

Potential benefits\:

- Reduces vocabulary size.
- Groups certain inflected forms together.
- May improve generalization when training data is limited.
- Can make some lexical features more consistent.

Potential drawbacks\:

- May remove useful grammatical distinctions.
- May introduce incorrect lemmas.
- Adds preprocessing cost.
- May provide little benefit when using contextual Transformer models.

The best approach is to compare models with and without lemmatization using the same training/test split and evaluation metrics.

## 9. Common mistakes in lemmatization

| Mistake | Why it is a problem | Better approach |
|--------|--------|--------|
| Assuming lemmatization is suffix removal | Irregular words need lexical knowledge | Use a proper lemmatizer |
| Using NLTK without POS information | Defaults may produce unexpected results | Supply the correct POS category |
| Assuming every lemma is correct | Taggers and lemmatizers can make errors | Inspect results on representative samples |
| Removing all stop words | Can remove negation or important context | Remove them only when appropriate |
| Lowercasing everything automatically | Case may carry information for some tasks | Decide based on the application |
| Lemmatizing before tokenization | Most lemmatizers operate on tokens | Use a proper NLP pipeline |
| Applying preprocessing inconsistently | Training and inference may produce different features | Reuse the same preprocessing pipeline |
| Assuming lemmatization is mandatory for Transformers | Subword tokenization and contextual representations work differently | Test whether it helps your model |

### An important example: negation

Consider these two reviews\:

- "The movie was good."
- "The movie was not good."

If you remove `not` as a stop word, the two reviews may become almost identical.

Lemmatization normally preserves `not` as a token; stop-word removal is a separate operation. Always evaluate preprocessing decisions according to the task.

## 11. Practical mini-project

Build a small **movie-review lemmatization analyzer** using spaCy.

Your program should\:

1. Load a CSV containing a `review` column.
2. Handle missing review values.
3. Generate lemmas for every review.
4. Save the results in a new `lemmas` column.
5. Compare the number of unique words before and after lemmatization.
6. Export the result to a new CSV file.

Starter code\:

```python
import pandas as pd
import spacy

nlp = spacy.load("en_core_web_sm")

df = pd.read_csv("movie_reviews.csv")

df["review"] = df["review"].fillna("").astype(str)

# Original vocabulary size
original_vocab = set(
    word.lower()
    for text in df["review"]
    for word in text.split()
)

# Lemmatize the reviews
df["lemmas"] = [
    [
        token.lemma_.lower()
        for token in doc
        if not token.is_punct
    ]
    for doc in nlp.pipe(df["review"], batch_size=128)
]

# Normalized vocabulary
lemma_vocab = {
    lemma
    for lemmas in df["lemmas"]
    for lemma in lemmas
}

print("Original vocabulary size:", len(original_vocab))
print("Lemma vocabulary size:", len(lemma_vocab))

df.to_csv("movie_reviews_lemmatized.csv", index=False)
```

**Note\:** The original vocabulary calculation above is a simple whitespace-based baseline, so punctuation may inflate its count. For a fairer comparison, calculate both vocabulary sizes using the same tokenization strategy.

- **Lemma\:** The canonical form of a word, such as `run` for `running`\.
- **Stemming\:** Reduces words using simpler rules; output may not be a valid word.
- **POS-aware lemmatization\:** Uses grammatical information to improve lemma selection.
- **NLTK\:** Useful for learning traditional NLP concepts and experimenting with WordNet.
- **spaCy\:** Convenient for practical NLP pipelines and large text datasets.
- **TF-IDF integration\:** Lemmatization can normalize word variations before vectorization.
