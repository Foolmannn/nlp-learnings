# Machine Learning Approaches for Text Classification — Detailed Guide

In NLP, text classification can be solved using several machine learning approaches. The main differences are how text is represented, how the model learns patterns, and how it decides which class a document belongs to.

Since you've already studied text preprocessing, Bag of Words, TF-IDF, and Word2Vec, let's focus on the actual ML approaches, their mathematics, how they work, Python implementations, and when to use each one.

# 1. Overview of ML approaches

Text classification approaches can be grouped into four broad categories.

![Multinomial Naive Bayes Classifier | by Yoann Mocquin | TDS Archive | Medium](probabilistic_approach.jpg)

1\. Probabilistic approaches

Multinomial Naive Bayes, Bernoulli Naive Bayes

Estimate class probabilities using word frequencies and probability theory.

![Medium](linear_approach.jpg)

2\. Linear approaches

Logistic Regression, Linear SVM, SGD Classifier, Perceptron

Learn decision boundaries in a numerical text feature space.

![Virtual Labs](tree_based_approach.jpg)

3\. Tree-based approaches

Decision Tree, Random Forest, Gradient Boosting

Learn rules and feature interactions from text-derived numerical features.

![Detecting Fake Reviews Generated by Language Models | by Shaunak Divine | Medium](neural_representation_approach.jpg)

4\. Neural representation-based approaches

MLP, CNN, RNN, LSTM, GRU, transformers

Learn or use dense representations of words and documents to classify text.

These groups are not mutually exclusive. For example, Logistic Regression can classify TF-IDF features or sentence embeddings. Similarly, an SVM can work with either sparse text vectors or dense embeddings.

One crucial principle: the classifier and the text representation are separate components.

For example:

\\[ \text{Raw text}\rightarrow\text{TF-IDF}\rightarrow\text{Linear SVM}\rightarrow\text{Label} \\]

Changing TF-IDF to sentence embeddings changes the features, while changing Linear SVM to Logistic Regression changes the learning algorithm.

# 3. Multinomial Naive Bayes

Multinomial Naive Bayes (MNB) is one of the most widely used traditional ML algorithms for text classification.

It is based on Bayes' theorem and is particularly suitable for features representing word counts. It also commonly works with nonnegative TF-IDF features.

## 3.1 Intuition

Suppose a classifier has learned from these examples:

| Text                           | Class    |
| ------------------------------ | -------- |
| Free prize, claim now          | Spam     |
| Win a free reward              | Spam     |
| Meeting scheduled for tomorrow | Not spam |
| Please send the meeting report | Not spam |

When a new message contains "free prize," the model estimates how likely those words are under each class.

It then predicts the class with the highest posterior probability.

## 3.2 Mathematical foundation

Bayes' theorem:

\\[ P(C\mid d)=\frac{P(d\mid C)P(C)}{P(d)} \\]

Here:

- \\(C\\) is a class.
- \\(d\\) is a document.
- \\(P(C)\\) is the prior probability of the class.
- \\(P(d\mid C)\\) is the likelihood of the document under that class.
- \\(P(C\mid d)\\) is the posterior probability.

For a document containing word features, the Naive Bayes assumption gives us:

\\[ P(d\mid C)\propto\prod\_{j=1}^{V}P(w_j\mid C)^{x_j} \\]

where:

- \\(V\\) is the vocabulary size.
- \\(x_j\\) is the count or feature value for word \\(j\\).
- \\(P(w_j\mid C)\\) is the learned class-conditional probability of that word.

The predicted class is:

\\[ \hat C=\arg\max_C P(C\mid d) \\]

In implementation, the model normally calculates logarithmic scores to avoid numerical underflow.

## 3.3 How are word probabilities calculated?

Suppose the spam class contains the following word counts:

| Word  | Count |
| ----- | ----- |
| free  | 30    |
| win   | 20    |
| prize | 10    |

The total word count is 60. Without smoothing:

\\[ P(\text{free}\mid\text{spam})=\frac{30}{60}=0.5 \\]

But consider a word that never appeared in spam messages. Its estimated probability would be zero, potentially making the entire document likelihood zero.

Naive Bayes addresses this using Laplace smoothing:

\\[ P(w_j\mid C)= \frac{N\_{j,C}+\alpha} {N_C+\alpha V} \\]

where:

- \\(N\_{j,C}\\) is the count of word \\(j\\) in class \\(C\\).
- \\(N_C\\) is the total word count for that class.
- \\(V\\) is the vocabulary size.
- \\(\alpha\\) is the smoothing parameter, usually 1 for Laplace smoothing.

Smoothing gives unseen words a nonzero probability.

## 3.4 Implement it in Python

```
from sklearn.naive_bayes import MultinomialNBfrom sklearn.metrics import classification_reportnb_model = MultinomialNB(alpha=1.0)nb_model.fit(X_train_vec, y_train)nb_pred = nb_model.predict(X_test_vec)print(classification_report(    y_test,    nb_pred,    zero_division=0))
```

For a new review:

```
new_reviews = [    "The movie was fantastic",    "The movie was boring"]new_vectors = tfidf.transform(new_reviews)print(nb_model.predict(new_vectors))
```

You can also inspect class probabilities:

```
print(nb_model.predict_proba(new_vectors))print(nb_model.classes_)
```

## 3.5 Advantages and limitations

Advantages:

- Fast training and prediction.
- Works well with high-dimensional sparse text.
- Needs relatively little computational power.
- Often effective for spam filtering and topic classification.

Limitations:

- Assumes conditional independence of features given the class.
- Does not directly model word order or phrase composition.
- Probability estimates can be poorly calibrated.
- May underperform a well-tuned linear SVM or Logistic Regression on some datasets.

### Bernoulli Naive Bayes vs. Multinomial Naive Bayes

Bernoulli Naive Bayes models whether a word is present or absent, while Multinomial Naive Bayes models word occurrence counts.

For example:

`"good good movie"`

- Multinomial representation: `good = 2`, `movie = 1`.
- Bernoulli representation: `good = 1`, `movie = 1`.

Bernoulli Naive Bayes can be useful when word presence matters more than repetition.

```
from sklearn.naive_bayes import BernoulliNBbernoulli_model = BernoulliNB()bernoulli_model.fit(X_train_vec, y_train)
```

This code is valid, although Bernoulli Naive Bayes is most naturally used with binary word-presence features. A `CountVectorizer(binary=True)` representation is a more direct choice for it.

# 4. Logistic Regression

Logistic Regression is one of the strongest starting points for traditional text classification.

Although its name includes "regression," it predicts categorical labels.

## 4.1 Intuition

Imagine that TF-IDF creates these features:

| Text                        | excellent | amazing | terrible | boring |
| --------------------------- | --------- | ------- | -------- | ------ |
| Excellent and amazing movie | 0.7       | 0.6     | 0.0      | 0.0    |
| Terrible and boring movie   | 0.0       | 0.0     | 0.7      | 0.6    |

Logistic Regression learns a weight for each feature.

Words associated with positive reviews may receive positive weights for the positive class, while words associated with negative reviews may receive negative weights.

These are learned from training data, not assigned manually.

## 4.2 Mathematical foundation

First, calculate a linear score:

\\[ z=w^Tx+b \\]

where \\(x\\) is the TF-IDF vector, \\(w\\) contains learned weights, and \\(b\\) is a bias term.

For binary classification, convert the score into a probability using the sigmoid function:

\\[ \sigma(z)=\frac{1}{1+e^{-z}} \\]

Thus:

\\[ P(y=1\mid x)=\sigma(w^Tx+b) \\]

Suppose the model estimates:

\\[ P(\text{positive}\mid x)=0.85 \\]

If the classification threshold is 0.5, the predicted class is positive.

The model learns its weights by minimizing logistic loss, typically with regularization.

For binary labels \\(y_i\in\\{0,1\\}\\), the binary cross-entropy loss is:

\\[ J(w,b)= -\frac{1}{N}\sum\_{i=1}^{N} \left[ y_i\log p_i+ (1-y_i)\log(1-p_i) \right] \\]

Regularization adds a penalty that discourages excessively large coefficients.

## 4.3 Train Logistic Regression

```
from sklearn.linear_model import LogisticRegressionlr_model = LogisticRegression(    C=1.0,    max_iter=1000,    random_state=42)lr_model.fit(X_train_vec, y_train)lr_pred = lr_model.predict(X_test_vec)print(classification_report(    y_test,    lr_pred,    zero_division=0))
```

The `C` parameter controls the inverse strength of regularization:

- Smaller `C`: stronger regularization.
- Larger `C`: weaker regularization.

## 4.4 Inspect important words

One useful feature of linear models is that we can inspect their learned coefficients.

```
import numpy as npfeature_names = tfidf.get_feature_names_out()# Binary Logistic Regression has one coefficient row.weights = lr_model.coef_[0]top_positive = np.argsort(weights)[-10:][::-1]top_negative = np.argsort(weights)[:10]print("Words favoring the positive class:")for i in top_positive:    print(feature_names[i], weights[i])print("\nWords favoring the negative class:")for i in top_negative:    print(feature_names[i], weights[i])
```

This assumes the learned positive class is the class of interest. In scikit-learn's binary Logistic Regression, the coefficient row corresponds to `lr_model.classes_[1]`.

These coefficients describe the contribution of individual features to the linear score, holding the other features fixed. They are not proof that a word causes positive or negative sentiment.

## 4.5 Advantages and limitations

Advantages:

- Excellent baseline for TF-IDF features.
- Efficient on many sparse text datasets.
- Supports binary and multiclass classification.
- Can produce class probabilities.
- Coefficients are inspectable.

Limitations:

- The decision boundary is linear in the chosen feature space.
- It cannot automatically understand deep contextual relationships.
- Regularization and preprocessing choices can affect performance.

When to use it: General-purpose sentiment analysis, email classification, document categorization, and many practical NLP tasks.

# 5. Support Vector Machine (SVM)

Support Vector Machines are especially important in traditional NLP because linear SVMs often perform well on high-dimensional sparse text.

## 5.1 Intuition

Imagine that every review is represented as a point in a numerical feature space.

Positive reviews occupy some regions, while negative reviews occupy others. An SVM tries to find a boundary that separates the classes with a large margin.

![Support vector machines | Predictive Analytics in Business Class Notes](max_margin_classifier.jpg)



Conceptual illustration of a maximum-margin classifier. Actual text data has thousands of dimensions, not just two.

The examples closest to the decision boundary are called support vectors. They play a central role in determining the separating boundary.

## 5.2 Mathematical foundation

For a linear SVM, the decision function is:

\\[ f(x)=w^Tx+b \\]

The predicted class depends on the sign of the score:

\\[ \hat y=\operatorname{sign}(f(x)) \\]

For labels \\(y_i\in\\{-1,+1\\}\\), a common soft-margin objective is:

\\[ \min\_{w,b} \frac{1}{2}\\|w\\|^2+ C\sum\_{i=1}^{N}\max(0,1-y_i f(x_i)) \\]

The second term is hinge loss:

\\[ L_i=\max(0,1-y_i f(x_i)) \\]

The first term encourages a wider margin; the second penalizes examples that violate the desired margin.

The parameter \\(C\\) balances the two.

## 5.3 Train a Linear SVM

```
from sklearn.svm import LinearSVCsvm_model = LinearSVC(    C=1.0,    random_state=42)svm_model.fit(X_train_vec, y_train)svm_pred = svm_model.predict(X_test_vec)print(classification_report(    y_test,    svm_pred,    zero_division=0))
```

Unlike Logistic Regression, `LinearSVC` does not directly provide class probabilities. Its `decision_function()` provides decision scores.

```
scores = svm_model.decision_function(X_test_vec)print(scores)
```

For binary classification, scores on one side of the decision boundary correspond to one class and scores on the other side correspond to the other class. Use `svm_model.classes_` to identify the class ordering.

## 5.4 Linear vs. kernel SVM

A kernel SVM can learn nonlinear decision boundaries using a kernel function.

For example, the RBF kernel is:

\\[ K(x,z)=e^{-\gamma\\|x-z\\|^2} \\]

However, a nonlinear kernel can become computationally expensive as the training set grows. For sparse, high-dimensional text, `LinearSVC` is often a more practical first choice.

Advantages:

- Often strong performance on sparse TF-IDF features.
- Effective in high-dimensional feature spaces.
- Good generalization when appropriately regularized.

Limitations:

- Does not directly provide probabilities in its standard `LinearSVC` implementation.
- Parameter tuning can matter.
- Nonlinear kernel variants can be expensive for large text datasets.

When to use it: Large text datasets, sentiment analysis, spam detection, and document categorization.

# 6. Stochastic Gradient Descent (SGD) Classifier

An SGD classifier is useful when the training dataset is large and updating a model using all examples at once becomes expensive.

SGD is an optimization method rather than a single classification algorithm. In scikit-learn, `SGDClassifier` can use different loss functions to train different types of linear classifiers.

Common choices include:

- `loss="hinge"`: linear SVM-style classifier.
- `loss="log_loss"`: logistic regression-style classifier.
- `loss="perceptron"`: perceptron-style classifier.

## 6.1 How SGD works

Suppose we want to minimize an objective function \\(J(w)\\).

Instead of computing a gradient using every training example, SGD updates parameters using individual examples or small batches.

For one training example, a simplified update is:

\\[ w\_{t+1}=w_t-\eta\nabla J_i(w_t) \\]

where:

- \\(w_t\\) is the current parameter vector.
- \\(\eta\\) is the learning rate.
- \\(\nabla J_i(w_t)\\) is the gradient for an individual training example.

The model repeatedly updates its weights while processing the training data.

## 6.2 Implementation

```
from sklearn.linear_model import SGDClassifiersgd_model = SGDClassifier(    loss="log_loss",    max_iter=1000,    tol=1e-3,    random_state=42)sgd_model.fit(X_train_vec, y_train)sgd_pred = sgd_model.predict(X_test_vec)print(classification_report(    y_test,    sgd_pred,    zero_division=0))
```

This example uses logistic loss, so it learns a linear classifier with a logistic objective.

To use an SVM-style objective instead:

```
sgd_svm = SGDClassifier(    loss="hinge",    max_iter=1000,    random_state=42)
```

## 6.3 When should you use SGD?

SGD is particularly useful when:

- The dataset contains a very large number of documents.
- The vocabulary is large and features are sparse.
- You need incremental training using `partial_fit()`.
- You want to experiment with different linear classification losses.

However, SGD can be sensitive to learning-rate settings, regularization, and feature scaling. For moderate-sized datasets, standard Logistic Regression or Linear SVM may be easier to tune.

# 7. Perceptron

The Perceptron is one of the simplest linear classification algorithms and is historically important in machine learning.

It learns weights that separate classes using an error-driven update rule.

## 7.1 How it works

First, the model calculates a score:

\\[ z=w^Tx+b \\]

It predicts a class according to the sign of that score.

For a misclassified training example, the parameters are updated. With labels \\(y_i\in\\{-1,+1\\}\\), one common update is:

\\[ w\leftarrow w+\eta y_i x_i \\]

\\[ b\leftarrow b+\eta y_i \\]

where \\(\eta\\) is the learning rate.

If an example is correctly classified with a positive margin, a standard Perceptron update is not required for that example.

## 7.2 Implementation

```
from sklearn.linear_model import Perceptronperceptron_model = Perceptron(    max_iter=1000,    random_state=42)perceptron_model.fit(X_train_vec, y_train)perceptron_pred = perceptron_model.predict(X_test_vec)print(classification_report(    y_test,    perceptron_pred,    zero_division=0))
```

## 7.3 Advantages and limitations

Advantages:

- Simple and fast.
- Works with sparse text features.
- Provides a useful introduction to linear classifiers.

Limitations:

- Does not directly provide probabilities.
- Can be sensitive to data ordering and parameters.
- Does not optimize the same probabilistic objective as Logistic Regression.
- Convergence to a perfect separating boundary is guaranteed only under particular conditions, such as linearly separable training data.

For practical text classification, Logistic Regression, Linear SVM, and SGD are often stronger starting points. The Perceptron is still valuable for learning how a classifier updates its weights.

# 8. K-Nearest Neighbors (KNN)

KNN classifies a new text based on the labels of similar training documents.

Unlike Logistic Regression and SVM, KNN does not learn a conventional parametric decision boundary during training. Instead, it stores the training representations and finds nearby examples when a prediction is required.

## 8.1 How KNN works

Suppose the training dataset contains:

- "Amazing movie" — Positive
- "Wonderful acting" — Positive
- "Terrible film" — Negative
- "Boring story" — Negative

A new review arrives:

`"Amazing acting"`

KNN represents the text numerically, calculates its distance from training examples, and examines its \\(k\\) nearest neighbors.

If \\(k=3\\) and two neighbors are positive while one is negative, the majority vote predicts positive.

## 8.2 Distance calculation

Euclidean distance between two vectors is:

\\[ d(x,z)=\sqrt{\sum\_{j=1}^{V}(x_j-z_j)^2} \\]

For text, cosine distance is often more suitable because it compares the direction of the vectors:

\\[ d\_{\cos}(x,z)=1- \frac{x\cdot z}{\\|x\\|\\|z\\|} \\]

TF-IDF vectors are often L2-normalized, making cosine similarity a natural measure of lexical similarity.

## 8.3 Implementation

```
from sklearn.neighbors import KNeighborsClassifierknn_model = KNeighborsClassifier(    n_neighbors=3,    metric="cosine",    algorithm="brute")knn_model.fit(X_train_vec, y_train)knn_pred = knn_model.predict(X_test_vec)print(classification_report(    y_test,    knn_pred,    zero_division=0))
```

For sparse text matrices, brute-force neighbor search is a straightforward option. Prediction can become slow when the training dataset is large.

## 8.4 Advantages and limitations

Advantages:

- Simple and intuitive.
- Can model nonlinear decision boundaries.
- Does not require a complex model-training procedure.

Limitations:

- Prediction may be expensive because it compares new samples with training data.
- Results depend on the distance metric and value of \\(k\\).
- High-dimensional sparse text often makes meaningful nearest-neighbor relationships harder to identify.
- Similar vocabulary does not always mean similar meaning.

Practical note: KNN is worth experimenting with to understand similarity-based classification, but it is not usually my first choice for a large TF-IDF text classification problem.

# 9. Decision Tree and Random Forest

Tree-based models learn feature-based rules rather than a single linear boundary.

## 9.1 Decision Tree

A Decision Tree repeatedly divides the training data according to feature values.

For example, a simplified sentiment tree might learn rules involving features such as:

```
Does the review contain "terrible"?
             |
          Yes / No
           /     \
      Negative   Check another feature
```

The actual tree can split on numerical TF-IDF values, such as whether the weight for a particular term exceeds a threshold.

### Splitting criteria

One common criterion is Gini impurity:

\\[ Gini(S)=1-\sum\_{c=1}^{K}p_c^2 \\]

where \\(p_c\\) is the proportion of class \\(c\\) within a node.

A node containing only one class has zero Gini impurity.

Another criterion is entropy:

\\[ H(S)=-\sum\_{c=1}^{K}p_c\log_2 p_c \\]

The tree chooses splits that reduce impurity according to its training criterion.

### Implementation

```
from sklearn.tree import DecisionTreeClassifiertree_model = DecisionTreeClassifier(    max_depth=20,    min_samples_leaf=2,    random_state=42)tree_model.fit(X_train_vec, y_train)tree_pred = tree_model.predict(X_test_vec)
```

The depth and minimum leaf size help control overfitting.

## 9.2 Random Forest

Random Forest combines many decision trees.

Each tree is trained with randomness in its sample selection and feature selection. For classification, the forest combines the individual tree predictions, typically through voting or averaged class probabilities.

The general idea is that combining diverse trees can reduce the instability of an individual decision tree.

### Implementation

```
from sklearn.ensemble import RandomForestClassifierrf_model = RandomForestClassifier(    n_estimators=200,    max_depth=30,    min_samples_leaf=2,    random_state=42,    n_jobs=-1)rf_model.fit(X_train_vec, y_train)rf_pred = rf_model.predict(X_test_vec)
```

## 9.3 Are tree-based methods good for text?

They can work, but there is an important trade-off.

Text vectors may contain tens of thousands of sparse features. Tree ensembles can struggle to use these features as effectively as linear models, and the resulting models may require considerable memory and computation.

Random Forest is often more natural for structured numerical data, such as customer age, purchase amount, and account activity, than for raw TF-IDF vectors.

For a text classification task, establish a Logistic Regression or Linear SVM baseline before investing in a tree ensemble.

# 10. Gradient boosting for text classification

Gradient boosting builds a sequence of weak learners, typically decision trees, where later learners aim to improve on errors made by earlier learners.

Popular implementations include XGBoost, LightGBM, and CatBoost.

## 10.1 How it works

The model begins with an initial prediction, then adds successive learners that improve the objective function.

Conceptually:

\\[ F_m(x)=F\_{m-1}(x)+\eta h_m(x) \\]

where:

- \\(F\_{m-1}(x)\\) is the current model.
- \\(h_m(x)\\) is the next tree.
- \\(\eta\\) is the learning rate.

Unlike a simple voting ensemble, boosting constructs learners sequentially to improve the existing model.

## 10.2 Using XGBoost

If XGBoost is installed, a simple binary text classification example is:

```
pip install xgboost
```

```
from xgboost import XGBClassifier# Convert text labels to binary numerical labels.y_train_bin = (y_train == "positive").astype(int)y_test_bin = (y_test == "positive").astype(int)xgb_model = XGBClassifier(    n_estimators=200,    max_depth=4,    learning_rate=0.05,    objective="binary:logistic",    eval_metric="logloss",    random_state=42)xgb_model.fit(X_train_vec, y_train_bin)xgb_pred = xgb_model.predict(X_test_vec)
```

Here, `0` represents negative and `1` represents positive.

XGBoost can process numerical text features, including sparse features. However, a large sparse TF-IDF matrix may still make training relatively expensive, and boosting does not automatically provide a semantic understanding of words.

Gradient boosting is worth considering when you have structured metadata in addition to text—for example, review length, user ratings, product category, and numerical customer features—or when validation experiments show that it performs well on your text representation.

# 11. Neural networks for text classification

Traditional ML classifiers generally depend on a predefined text representation such as TF-IDF. Neural networks can instead learn useful representations from token sequences or use pretrained embeddings.

Let's look at the major neural approaches.

## 11.1 Multilayer Perceptron (MLP)

An MLP is a feed-forward neural network with one or more hidden layers.

A simple architecture is:

\\[ \text{TF-IDF features} \rightarrow \text{Dense layer} \rightarrow \text{ReLU} \rightarrow \text{Output layer} \\]

The hidden layer can learn nonlinear combinations of text features.

For example, it may learn interactions between features associated with negation and sentiment, although its effectiveness depends on the data and architecture.

### Basic implementation

```
from sklearn.neural_network import MLPClassifiermlp_model = MLPClassifier(    hidden_layer_sizes=(128, 64),    activation="relu",    max_iter=300,    early_stopping=True,    random_state=42)mlp_model.fit(X_train_vec, y_train)mlp_pred = mlp_model.predict(X_test_vec)
```

This is a basic example using scikit-learn. A large TF-IDF feature space can make MLPs memory-intensive, and they may need more tuning than linear classifiers.

## 11.2 Convolutional Neural Network (CNN)

CNNs can classify text by learning local patterns in sequences of word embeddings.

For example, a CNN may learn useful filters for patterns such as:

- "very good"
- "not worth"
- "highly recommended"

A simplified architecture is:

Token sequence

Word embeddings

1D convolution + activation

Pooling

Classification layer

CNNs are good at extracting local patterns, but they do not automatically capture long-range relationships as effectively as many sequence-based or attention-based architectures.

## 11.3 Recurrent Neural Networks (RNNs)

An RNN processes tokens sequentially, updating its hidden state at each time step.

\\[ h_t=f(W_xx_t+W_hh\_{t-1}+b) \\]

where:

- \\(x_t\\) is the representation of the current token.
- \\(h\_{t-1}\\) is the previous hidden state.
- \\(h_t\\) is the updated hidden state.

The hidden state carries information from earlier tokens, allowing the model to use sequence order.

However, traditional RNNs can struggle to learn long-range dependencies because of vanishing or exploding gradients.

## 11.4 LSTM and GRU

LSTMs and GRUs are gated recurrent architectures designed to control the flow of information through the sequence.

They can learn which information should be retained, updated, or discarded.

For example, the meaning of:

`"I thought the movie would be good, but it was disappointing"`

depends on how the later phrase changes the interpretation of the earlier words.

An LSTM or GRU can model these sequence relationships. They require more training resources than a basic linear classifier and are not automatically superior to modern pretrained transformers.

## 11.5 Transformers and BERT

Transformers use attention mechanisms to model relationships between tokens.

For example:

`"The camera was expensive, but it was worth it."`

A contextual model can use surrounding words to learn representations that distinguish how terms function within the sentence.

BERT is a pretrained transformer encoder. For classification, it is common to:

1. Tokenize the input using the model's tokenizer.
2. Convert tokens to input IDs and attention masks.
3. Process them through the pretrained encoder.
4. Feed a sequence representation into a classification head.
5. Fine-tune the model using labeled examples.

Transformers often perform well when contextual understanding is important, but they require more compute and memory than traditional ML approaches.

# 12. Word2Vec and document embeddings with traditional classifiers

Because you have been studying Word2Vec, this distinction is important.

Word2Vec is a word representation learning method, not a complete text classification algorithm.

You can use Word2Vec embeddings as input features for a classifier.

Suppose each word has a 300-dimensional embedding:

\\[ v\_{\text{good}}\in\mathbb{R}^{300} \\]

A review containing 20 words can be represented by averaging the word embeddings:

\\[ v\_{\text{review}}= \frac{1}{20}\sum\_{i=1}^{20}v\_{w_i} \\]

The resulting document vector has 300 dimensions, regardless of whether the review contains 20 words or 200 words.

You can then train Logistic Regression, an SVM, or another suitable classifier on these vectors.

## Example: Average Word2Vec embeddings

Suppose you've already trained a Gensim Word2Vec model named `w2v_model`.

```
import numpy as npdef document_vector(text, w2v_model):    vectors = [        w2v_model.wv[word]        for word in text.lower().split()        if word in w2v_model.wv    ]    if not vectors:        return np.zeros(w2v_model.vector_size)    return np.mean(vectors, axis=0)
```

Create the feature matrices:

```
X_train_w2v = np.vstack([    document_vector(text, w2v_model)    for text in X_train])X_test_w2v = np.vstack([    document_vector(text, w2v_model)    for text in X_test])
```

Train a classifier:

```
from sklearn.linear_model import LogisticRegressionw2v_classifier = LogisticRegression(    max_iter=1000,    random_state=42)w2v_classifier.fit(X_train_w2v, y_train)predictions = w2v_classifier.predict(X_test_w2v)
```

This approach assumes `w2v_model` has already been trained or loaded and is available in your Python environment.

There is an important limitation: averaging embeddings loses word order. As a result, "good but not excellent" and "not good but excellent" may receive similar representations.

You can improve document representations by using weighted averages, Doc2Vec, pretrained sentence embeddings, or contextual transformers.

# 13. How to compare the ML approaches fairly

Do not compare algorithms by training each one on a different split or using different test data. Keep the data split consistent.

A convenient approach is to define multiple complete pipelines and compare them using cross-validation.

# 14. Final comparison of ML approaches

| Algorithm               | Typical text features            | Main strength                          | Main limitation                                 |
| ----------------------- | -------------------------------- | -------------------------------------- | ----------------------------------------------- |
| Multinomial Naive Bayes | Counts, TF-IDF                   | Fast and simple                        | Independence assumption                         |
| Logistic Regression     | TF-IDF, embeddings               | Strong baseline, probabilities         | Linear decision boundary                        |
| Linear SVM              | TF-IDF, embeddings               | Strong high-dimensional classification | No direct probabilities in `LinearSVC`          |
| SGD Classifier          | Sparse TF-IDF                    | Scalable, incremental training         | Sensitive to optimization settings              |
| Perceptron              | Sparse TF-IDF                    | Simple linear learning                 | Less robust in many practical settings          |
| KNN                     | TF-IDF, embeddings               | Similarity-based classification        | Slow predictions on large datasets              |
| Decision Tree           | Numerical text features          | Interpretable rules                    | Can overfit; sparse text is challenging         |
| Random Forest           | Numerical text features          | Nonlinear feature interactions         | May be costly and less effective on sparse text |
| Gradient Boosting       | Numerical text features          | Powerful nonlinear learning            | Requires tuning; not inherently semantic        |
| MLP                     | TF-IDF, embeddings               | Learns nonlinear combinations          | More tuning and computation                     |
| CNN / LSTM / GRU        | Token sequences, embeddings      | Learns local or sequential patterns    | More complex training                           |
| Transformers            | Contextual token representations | Rich contextual understanding          | Greater resource requirements                   |

## 15. Which approaches should you learn first?

For your NLP learning journey, I recommend this sequence:

1. Multinomial Naive Bayes: Understand how class probabilities and word frequencies work.
2. Logistic Regression: Understand sigmoid probabilities, loss functions, regularization, and class prediction.
3. Linear SVM: Understand margins, support vectors, and hinge loss.
4. SGD Classifier: Understand optimization and scalable linear learning.
5. Model evaluation and tuning: Compare precision, recall, macro F1, cross-validation, and hyperparameters.
6. Word2Vec and sentence embeddings: Experiment with dense document representations.
7. Deep learning and transformers: Move to CNNs, LSTMs, and fine-tuned BERT models.

My practical recommendation is to begin with TF-IDF + Multinomial Naive Bayes, TF-IDF + Logistic Regression, and TF-IDF + Linear SVM. These three give you a solid foundation for understanding how traditional ML models classify text.

After that, build a larger movie-review sentiment classifier and compare the three approaches using macro F1-score, precision, recall, and a confusion matrix. This will teach you much more than simply training a single model and checking its accuracy.
